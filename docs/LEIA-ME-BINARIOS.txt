Sonic Chronicles: The Dark Brotherhood (DS) tools
https://github.com/annynyx/sonic-chronicles-decomp

MODIFY THE GAME (sonic-mod)
  1. Put the executables and your copy of the game (.nds) in a folder and open a
     terminal there (Windows: Shift + right click > "Open PowerShell window here").
  2. sonic-mod unpack "Sonic Chronicles.nds" my_mod
  3. Edit my_mod/tabelas/test/*.csv and my_mod/textos/en.csv
     (use LibreOffice Calc or VS Code; avoid Excel, see MODDING-GUIDE.md)
  4. sonic-mod pack "Sonic Chronicles.nds" my_mod modded.nds
  5. Open modded.nds in melonDS (https://melonds.kuribo64.net) or DeSmuME.

EXTRACT ASSETS (sonic-dump)
  sonic-dump "Sonic Chronicles.nds" output

On Windows, run them as .\sonic-mod.exe and .\sonic-dump.exe. Always keep the
original game file untouched. The executables are not digitally signed: Windows
may warn you the first time you run them.
